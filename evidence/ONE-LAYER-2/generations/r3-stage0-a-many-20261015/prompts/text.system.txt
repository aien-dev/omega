You write a small program for the Omega machine. The task says which function to write: its name,
its parameter types and its return type. You may add helper functions before it.

Values and rules (the same whatever form you write the program in):

- Types: bool, u8, u16, u32, u64 (unsigned), i8, i16, i32, i64 (signed, two's complement).
- No implicit conversions: the two operands of an arithmetic, bitwise or comparison operation have
  the same type (a shift amount may be any integer type). Convert explicitly.
- Unsigned arithmetic wraps modulo 2^width.
- Signed +, -, *, negation and << must give a representable result, otherwise the run stops with
  trap 1 (overflow).
- Division truncates toward zero; remainder has the sign of the dividend. A divisor of 0 stops the
  run with trap 2 (division by zero). Signed MIN / -1 is trap 1.
- An array index out of bounds is trap 3. A loop that runs past its bound is trap 4.
- A conversion to a type that cannot hold the value is trap 5 (conversion out of range).
- A shift amount outside 0..width-1 is trap 7.
- A trap ends the whole run; it is the function's outcome. Only trap where the task asks for one.

Answer with exactly one fenced code block (three backticks) that holds the complete program and
nothing else. Text outside the block is ignored.

REPRESENTATION: text

Write the program as OSC text, the language below (from docs/osc/OSC-1-DESIGN.md).

Grammar (EBNF):


```
unit      = { fn_def } EOF ;
fn_def    = "fn" NAME "(" [ param { "," param } ] ")" [ "->" type ]
            [ "requires" clause ] [ "ensures" clause ] block ;
param     = NAME ":" ptype ;                        (* at most 6 params *)
ptype     = type | arr_type ;
arr_type  = "own" "[" type ";" INT "]"              (* owner, moved into the callee *)
          | "&" "[" type ";" INT "]"                (* shared borrow *)
          | "&" "mut" "[" type ";" INT "]" ;        (* mutable borrow *)
type      = "u8" | "u16" | "u32" | "u64" | "i8" | "i16" | "i32" | "i64" | "bool" ;
clause    = { token } ;          (* up to "ensures" / "{" at paren depth 0; recorded text *)
block     = "{" { stmt } "}" ;
stmt      = "let" [ "mut" ] NAME ":" type "=" expr ";"
          | "let" NAME ":" "own" "[" type ";" INT "]" "=" "alloc" "(" expr ")" ";"
          | "let" NAME ":" "own" "[" type ";" INT "]" "=" NAME ";"          (* move *)
          | "let" [ "mut" ] NAME ":" ( "&" | "&" "mut" ) "[" type ";" INT "]" "=" borrow ";"
          | NAME "=" ( expr | borrow ) ";"                (* mut scalar, or mut borrow binding *)
          | NAME "[" expr "]" "=" expr ";"
          | "if" expr block [ "else" ( block | if_stmt ) ]
          | "while" expr "bound" INT block
          | "for" NAME "in" INT ".." INT block             (* i: i64, half-open, literal ends *)
          | "return" [ expr ] ";"
          | call ";"
          | block ;
borrow    = "&" NAME | "&" "mut" NAME ;
expr      = lor ;
lor       = land { "||" land } ;                (* short-circuit *)
land      = cmp { "&&" cmp } ;                  (* short-circuit *)
cmp       = bor [ cmp_op bor ] ;                (* non-associative *)
bor       = bxor { "|" bxor } ;
bxor      = band { "^" band } ;
band      = shift { "&" shift } ;
shift     = add { ( "<<" | ">>" ) add } ;
add       = mul { ( "+" | "-" ) mul } ;
mul       = unary { ( "*" | "/" | "%" ) unary } ;
unary     = ( "-" | "~" | "!" ) unary | postfix ;
postfix   = primary [ "as" type ] ;
primary   = INT | "true" | "false" | NAME | NAME "[" expr "]" | call | "(" expr ")" ;
call      = NAME "(" [ arg { "," arg } ] ")" ;
arg       = expr | borrow ;                     (* an owner NAME as an `own` arg is a move *)
cmp_op    = "==" | "!=" | "<" | "<=" | ">" | ">=" ;
```

Literals, comments and identifiers are spelled as in V0 (decimal, `0x`, `0b`;
`//` and `/* */`). Precedence differs from V0 only by the added levels; every V0
operator keeps its V0 meaning. `free`, `drop`, `delete`, `dealloc` are reserved
and are a syntax error: destruction has no surface syntax, so a forgotten free
is inexpressible (III.8).


Static rules:


Types. No implicit conversion: both operands of a binary operator have the
identical type (shift: the amount may be any integer type), comparison operands
have the identical type, `if`/`while` conditions and `&& || !` operands are
`bool`. `as` converts between integer types only (checked at run time). The
array element type is an integer type or bool; N is 1..64.

Literals. A literal gets its type from the context (let annotation, the other
operand, the parameter / return / element type it is passed to, the `as`
source is refused for literals). A literal with no context is refused
(ambiguous width, as in V0); a literal that does not fit its type is refused
(`overflow-unsafe`).

Overflow-unsafe, refused at compile time: a constant expression of a signed
type whose value overflows; a literal shift amount >= width; a literal zero
divisor; a negative literal for an unsigned type.

Names. Every name is defined before use, in an enclosing scope. Shadowing in
an inner scope is refused (keeps diagnostics unambiguous). Functions are called
only after their definition (no recursion, no forward reference).

Loops. `while` without `bound N` is refused (`unbounded loop`). `for` ends must
be integer literals with A <= B. N and B - A are at most 1_000_000. A `while`
that would start iteration N+1 traps with OSC_TRAP_LOOP_BOUND.

Return. Every path of a non-void function ends in `return expr;`. A function
returns a scalar only (no `->` arr_type in OSC-1).

Worked examples (14): each is a task as you receive it, then a correct program.

Example 1.

entry hash_step
params u32 u8
ret u32

Write a function hash_step that takes an unsigned 32-bit number h and an unsigned 8-bit number c
and returns h * 31 + c, computed in unsigned 32-bit arithmetic: the result wraps modulo 2^32. It
never traps.

```
fn hash_step(h: u32, c: u8) -> u32 {
    return h * 31 + (c as u32);
}
```

Example 4.

entry nibble_mirror
params u16
ret bool

Write a function nibble_mirror that takes an unsigned 16-bit number x and returns true when its four
4-bit groups read the same from both ends: bits 0-3 equal bits 12-15, and bits 4-7 equal bits 8-11.
It never traps.

```
fn nibble_mirror(x: u16) -> bool {
    let a: u16 = x & 15;
    let b: u16 = (x >> 4) & 15;
    let c: u16 = (x >> 8) & 15;
    let d: u16 = x >> 12;
    return a == d && b == c;
}
```

Example 5.

entry rotl8
params u8 u8
ret u8

Write a function rotl8 that takes two unsigned 8-bit numbers x and k and rotates the 8 bits of x to
the left by k mod 8 places: bits shifted out on the left come back in on the right. It never traps.

```
fn rotl8(x: u8, k: u8) -> u8 {
    let s: u8 = k % 8;
    if s == 0 { return x; }
    return (x << s) | (x >> (8 - s));
}
```

Example 6.

entry count_digits
params u64
ret u8

Write a function count_digits that takes an unsigned 64-bit number n and returns the number of its
decimal digits as an unsigned 8-bit number. 0 has one digit. It never traps.

```
fn count_digits(n: u64) -> u8 {
    let mut x: u64 = n;
    let mut k: u8 = 1;
    while x >= 10 bound 20 {
        x = x / 10;
        k = k + 1;
    }
    return k;
}
```

Example 7.

entry has_digit
params u32 u8
ret bool

Write a function has_digit that takes an unsigned 32-bit number n and an unsigned 8-bit number d and
returns true when one of the decimal digits of n is d, false otherwise. 0 has the single digit 0.
When d is larger than 9 the answer is false. It never traps.

```
fn has_digit(n: u32, d: u8) -> bool {
    let t: u32 = d as u32;
    let mut x: u32 = n;
    let mut found: bool = x % 10 == t;
    while x >= 10 bound 10 {
        x = x / 10;
        if x % 10 == t { found = true; }
    }
    return found;
}
```

Example 8.

entry halve_or_dec_steps
params u32
ret u32

Write a function halve_or_dec_steps that takes an unsigned 32-bit number n and counts the steps that
bring it down to 1 or less, where one step halves n when n is even and subtracts 1 when n is odd.
Return the count as an unsigned 32-bit number (0 when n is 0 or 1). It never traps.

```
fn halve_or_dec_steps(n: u32) -> u32 {
    let mut x: u32 = n;
    let mut k: u32 = 0;
    while x > 1 bound 64 {
        if x % 2 == 0 { x = x / 2; } else { x = x - 1; }
        k = k + 1;
    }
    return k;
}
```

Example 9.

entry sum_range
params i32 i32
ret i64

Write a function sum_range that takes two signed 32-bit numbers lo and hi and returns the sum of all
integers from lo to hi inclusive, as a signed 64-bit number. When lo > hi the sum is 0. lo and hi
are always between -100000 and 100000. It never traps.

```
fn sum_range(lo: i32, hi: i32) -> i64 {
    let mut s: i64 = 0;
    let mut i: i32 = lo;
    while i <= hi bound 300000 {
        s = s + (i as i64);
        i = i + 1;
    }
    return s;
}
```

Example 10.

entry tri_kind
params u16 u16 u16
ret u8

Write a function tri_kind that takes three unsigned 16-bit side lengths a, b and c and returns, as an
unsigned 8-bit number: 0 when they cannot form a triangle (the sum of some two sides is at most the
third side; add in 32 bits so the sum cannot wrap), 1 when all three sides are equal, 2 when exactly
two sides are equal, 3 otherwise. It never traps.

```
fn tri_kind(a: u16, b: u16, c: u16) -> u8 {
    let x: u32 = a as u32;
    let y: u32 = b as u32;
    let z: u32 = c as u32;
    if x + y <= z || x + z <= y || y + z <= x {
        return 0;
    } else if a == b && b == c {
        return 1;
    } else if a == b || b == c || a == c {
        return 2;
    }
    return 3;
}
```

Example 11.

entry power_mod
params u32 u32 u32
ret u32

Write a function power_mod that takes three unsigned 32-bit numbers b, e and m and returns b to the
power e, modulo m (0 to the power 0 is 1). Work in unsigned 64-bit numbers: start with r = 1 mod m
and x = b mod m, then while e > 0: if e is odd, r = r * x mod m; x = x * x mod m; e = e / 2. Use a
helper function for "a * b mod m". When m is 0 the run stops with trap 2 (division by zero).

```
fn mod(a: u64, b: u64, m: u64) -> u64 {
    return a * b % m;
}

fn power_mod(b: u32, e: u32, m: u32) -> u32 {
    let mm: u64 = m as u64;
    let mut r: u64 = 1 % mm;
    let mut x: u64 = (b as u64) % mm;
    let mut k: u32 = e;
    while k > 0 bound 40 {
        if k % 2 == 1 { r = mod(r, x, mm); }
        x = mod(x, x, mm);
        k = k / 2;
    }
    return r as u32;
}
```

Example 12.

entry cube_xor_pair
params u8
ret u16

Write a function cube_xor_pair that takes an unsigned 8-bit number n. Fill a table T of 16 unsigned
16-bit entries with T[i] = i * i * i for i = 0 .. 15, and return T[n] xor T[n + 1], computing the
index n + 1 in 32 bits. When an index is past the table (n of 15 or more) the lookup is out of bounds
and the run stops with trap 3.

```
fn cube_xor_pair(n: u8) -> u16 {
    let t: own [u16; 16] = alloc(0);
    for i in 0 .. 16 {
        let v: u16 = i as u16;
        t[i] = v * v * v;
    }
    let j: u32 = n as u32;
    return t[j] ^ t[j + 1];
}
```

Example 13.

entry count_above
params i32 i32 i32 i32 i32
ret u8

Write a function count_above that takes five signed 32-bit numbers a, b, c, d and t and returns how
many of a, b, c and d are greater than t, as an unsigned 8-bit number. Put a, b, c and d in an array
of four and count with a helper function that reads the array. It never traps.

```
fn above(v: &[i32; 4], t: i32) -> u8 {
    let mut k: u8 = 0;
    for i in 0 .. 4 {
        if v[i] > t { k = k + 1; }
    }
    return k;
}

fn count_above(a: i32, b: i32, c: i32, d: i32, t: i32) -> u8 {
    let v: own [i32; 4] = alloc(0);
    v[0] = a;
    v[1] = b;
    v[2] = c;
    v[3] = d;
    return above(&v, t);
}
```

Example 14.

entry dot3
params i16 i16 i16 i16 i16 i16
ret i64

Write a function dot3 that takes six signed 16-bit numbers a, b, c, x, y, z and returns
a*x + b*y + c*z computed in signed 64-bit arithmetic. Convert the six values to signed 64-bit
numbers, store them in two arrays of three, and compute the sum with a helper function that reads
both arrays. It never traps.

```
fn dot(u: &[i64; 3], w: &[i64; 3]) -> i64 {
    let mut s: i64 = 0;
    for i in 0 .. 3 {
        s = s + u[i] * w[i];
    }
    return s;
}

fn dot3(a: i16, b: i16, c: i16, x: i16, y: i16, z: i16) -> i64 {
    let u: own [i64; 3] = alloc(0);
    let w: own [i64; 3] = alloc(0);
    u[0] = a as i64;
    u[1] = b as i64;
    u[2] = c as i64;
    w[0] = x as i64;
    w[1] = y as i64;
    w[2] = z as i64;
    return dot(&u, &w);
}
```
